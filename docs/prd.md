# 需求文档

## 1. 应用概述

- **应用名称**：DIDI单词助记
- **应用描述**：一款本地单词与词组学习工具，打开即用，无需注册与登录。支持手动添加（含整段文章智能拆词）与文件导入单词及词组，提供多种记忆模式（英汉选择题、汉英填字符、混合模式）、跟读练习、易错词专项训练及学习统计功能，所有数据持久化存储于本地。汉英模式中，单词采用填空形式（部分字母遮盖），词组采用完整填写形式（全部字母遮盖）；学习模式选择页支持按「仅单词」或「包含词组」筛选题库条目。

### 2.4 单词管理页

参考文件：DIDI单词助记-单词管理页.svg（文件链接：https://miaoda-conversation-file.cdn.bcebos.com/user-asmovv53jmkg/conv-asmoxmbk70u8/20260407/file-asmr05pldn9d.svg）

页面分为两个 Tab 区域：「手动添加」与「文件导入」，默认展示手动添加 Tab。

**公共区域（两个 Tab 共享）**
- 搜索栏：支持即时筛选，用户每输入一个字符，下方列表立即同步过滤，无需点击搜索按钮
- 列表展示所有已入库单词与词组，每条记录显示：单词/词组、词性、音标（词组可为空）、汉语翻译
- 支持删除单个条目

**去重开关**
- 页面提供「去重」开关，默认关闭
- 开关开启时：手动添加或文件导入的单词/词组，若与数据库中已有条目重复，则自动跳过；文件导入完成后，给出明显提示：「本次导入有 X 个重复条目已跳过」
- 开关关闭时：不执行去重，允许重复条目入库

#### 2.4.1 手动添加单词页（Tab：手动添加）

参考文件：DIDI单词助记-手动添加单词页.svg（文件链接：https://miaoda-conversation-file.cdn.bcebos.com/user-asmovv53jmkg/conv-asmoxmbk70u8/20260407/file-asmrqwkocf7o.svg）

**输入区域**
- 提供一个大文本输入框，支持两种输入方式：
  - 输入单个或多个单词/词组（每行一个）
  - 粘贴整段文章或任意文本内容
- 用户输入过程中，系统不进行任何实时查询或自动补全，避免页面卡顿
- 用户点击「确认添加」按钮后，系统执行以下操作：
  1. 自动将输入内容拆解为独立单词与词组列表（词组判定规则见 3.3）
  2. 为每个条目自动补充词性、国际音标（IPA，词组可为空）与汉语翻译
  3. 在页面下方展示拆解结果预览列表，每条记录显示：单词/词组、词性、音标、汉语翻译，用户可逐条修改
- 自动补充失败的字段留空，提示用户手动填写

**文件命名**
- 预览列表确认后，用户可选择：
  - 新建文件：为本次添加的条目命名，生成一个新的词库文件
  - 追加至已有文件：从已有词库文件列表中选择一个，将本次条目追加进去
- 确认后将条目存入本地数据库对应文件

#### 2.4.2 文件导入单词页（Tab：文件导入）

参考文件：DIDI单词助记-文件导入单词页.svg（文件链接：https://miaoda-conversation-file.cdn.bcebos.com/user-asmovv53jmkg/conv-asmoxmbk70u8/20260407/file-asmrvq7e991f.svg）

**导入区域**
- 支持导入格式：.txt、.csv、.xlsx、.doc、.pdf
- 系统自动识别并整理文件内容格式：无论原始文件排版是否规范，均自动将内容解析分解为「单词/词组 + 词性 + 音标 + 汉语翻译」的标准结构
- **词性缩写过滤规则**：在所有格式文件的解析过程中，若识别到词性缩写（如 n.、v.、adj.、adv.、prep.、conj.、pron.、interj.、art. 等常见词性标注），应将其识别为词性标注字段，不得将其作为独立单词或词组写入词库
- 对缺失词性、音标或翻译的条目，系统自动补充
- 解析完成后展示预览列表，用户可逐条确认或修改后点击「确认导入」批量导入至本地数据库
- 导入过程中展示进度状态
- **确认导入保障**：确认导入操作须确保将预览列表中所有已解析条目正确写入本地数据库，导入完成后给出成功提示及本次导入条目数量；若写入过程出现错误，需给出具体失败原因提示，支持重试

**已导入文件列表区域**
- 文件导入页下方展示一个列表框，显示当前数据库中所有已导入的词库文件
- 每条文件记录支持以下操作：
  - **重命名**：点击后可修改文件名称
  - **删除**：删除该文件及其包含的所有条目，删除前需二次确认
  - **预览**：点击后展示该文件包含的所有条目列表（单词/词组、词性、音标、汉语翻译）

### 2.5 学习模式选择页

参考文件：DIDI单词助记-学习模式选择页.svg（文件链接：https://miaoda-conversation-file.cdn.bcebos.com/user-asmovv53jmkg/conv-asmoxmbk70u8/20260407/file-asmrvq7e991c.svg）

- 提供三种学习模式入口：英汉模式、汉英模式、混合模式
- 点击后进入对应的模式选择/配置页

#### 2.5.1 英汉模式选择页

参考文件：DIDI单词助记-记忆模式选择页.svg（文件链接：https://miaoda-conversation-file.cdn.bcebos.com/user-asmovv53jmkg/conv-asmoxmbk70u8/20260407/file-asmrqwkocf7m.svg）

**题库筛选区域（页面上方）**
- 展示当前数据库中所有词库文件列表，用户可点选一个或多个文件作为本次记忆题库，支持多选
- 若选择多个文件，本次记忆的条目将从所选文件中随机抽取
- 提供**条目类型筛选**单选项，选项为：「全部」「仅单词」「包含词组」，默认选中「全部」
  - 「仅单词」：本次题库仅包含单个英文单词条目，排除词组
  - 「包含词组」：本次题库同时包含单词与词组条目
  - 「全部」：与「包含词组」效果一致，不做额外过滤

**本次记忆数量设置**
- 提供滑动条与手动输入框，用户可拖动滑动条或直接输入数字，设置本次记忆的条目数量
- 数量范围不超过所选文件（经条目类型筛选后）的条目总数
- 样式参考设置页「发音准确率阈值」组件

**易错词插入选项**
- 在数量设置下方提供单选框「易错词插入」
- 当设置页中「易错词插入」功能开启时：
  - 本选项默认为勾选状态
  - 用户可手动取消勾选，取消仅对本次生效，下次进入该页面自动恢复为勾选状态
  - 页面同步显示本次学习信息，格式为：「本次学习单词数量为 X 个单词，易错词 Y 个，共计 Z 个。（可点选「易错词插入」取消本次选择）」
    - 其中 X 为用户设置的条目数量，Y 为设置页中「易错词插入数量」的值，Z = X + Y
- 当设置页中「易错词插入」功能关闭时：
  - 本选项显示为灰色未勾选状态，不可操作
  - 选项旁提示：「可在设置页面中开启本功能」

**开始按钮**
- 仅保留「开始记忆」按钮，条目出现顺序默认为随机
- 点击「开始记忆」后进入英汉模式答题页

#### 2.5.2 英汉模式答题页（选择题模式）

参考文件：DIDI单词助记-英汉模式答题页.svg（文件链接：https://miaoda-conversation-file.cdn.bcebos.com/user-asmovv53jmkg/conv-asmoxmbk70u8/20260407/file-asms2qrco9vl.svg）

- 题干展示英文单词/词组及词性

- 用户点击选项后，立即反馈正确/错误状态，并自动进入下一题
- 答题完成后跳转至记忆结果报告页（英汉模式）
- 答题过程中记录正确率数据，存入本地统计数据库
- 答错的条目自动计入易错词库，并按规则更新易错权重（见 3.10）

#### 2.5.5 汉英模式答题页（填字符模式）

参考文件：DIDI单词助记-汉英模式答题页.svg（文件链接：https://miaoda-conversation-file.cdn.bcebos.com/user-asmovv53jmkg/conv-asmoxmbk70u8/20260407/file-asmr05pldn9e.svg）

- 题干展示汉语释义及词性
- **单词填空规则（方案A）**：
  - 若当前题目为单个英文单词，答案区域展示部分字母显示、部分字母用「*」遮盖的字符提示（如 F*t**r），遮盖字母数量与答案字母数一致
  - 若当前题目为英文词组，答案区域所有字母全部用「*」遮盖，不展示任何字母提示；词组中的空格保持可见，不参与遮盖
- 答案输入区域：每个需填写的字符对应一个独立输入框，填写完一个字符后光标自动跳转至下一个输入框
- 页面下方提供可点击的 26 键键盘布局（类似输入法键盘），用户可点击字母键填入对应输入框，也可使用系统键盘输入
- 答题完成后跳转至记忆结果报告页（汉英模式）
- 答题过程中记录正确率数据，存入本地统计数据库
- 答错的条目自动计入易错词库，并按规则更新易错权重（见 3.10）

参考文件：DIDI单词助记-记忆结果报告页-汉英模式.svg（文件链接：https://miaoda-conversation-file.cdn.bcebos.com/user-asmovv53jmkg/conv-asmoxmbk70u8/20260407/file-asmrqwkocf7k.svg）

- 与英汉模式结果报告页结构一致，内容以原型为准

#### 2.5.7 混合模式选择页

- 页面结构与英汉模式选择页一致，包含题库筛选、条目类型筛选、数量设置、易错词插入选项、「开始记忆」按钮
- 条目类型筛选逻辑与英汉模式选择页完全一致
- 易错词插入选项逻辑与英汉模式选择页完全一致
- 点击「开始记忆」后进入混合模式答题页

#### 2.5.8 混合模式答题页

- 答题内容兼具英汉模式（选择题）与汉英模式（填字符）两种题型，随机交替出现
- 英汉题型：展示英文单词/词组，提供 ABCD 四个汉语选项
- 汉英题型：展示汉语释义，提供字符填写输入框与 26 键键盘；单词采用部分遮盖填空，词组采用全部遮盖完整填写（规则同 2.5.5）
- 答题完成后跳转至记忆结果报告页（混合模式）
- 答题过程中记录正确率数据，存入本地统计数据库
- 答错的条目自动计入易错词库，并按规则更新易错权重（见 3.10）

#### 2.5.9 记忆结果报告页（混合模式）

- 与英汉模式结果报告页结构一致

### 2.6 跟读学习页

参考文件：DIDI单词助记-跟读学习页.svg（文件链接：https://miaoda-conversation-file.cdn.bcebos.com/user-asmovv53jmkg/conv-asmoxmbk70u8/20260407/file-asmr05pldn9g.svg）

- 展示当前单词/词组、词性、音标、汉语翻译
- 页面上提供小喇叭图标，用户点击后播放该单词/词组的标准发音音频
- 用户点击「开始朗读」按钮后，麦克风开启，录制用户发音
- 录制完成后，系统将用户发音与标准发音进行匹配分析，输出匹配度百分比
- 匹配度判定阈值从设置页的「发音准确率阈值」中读取，达到阈值则判定为发音合格
- 展示本次跟读的匹配度结果与合格/不合格状态
- 支持翻页切换至下一个单词/词组继续跟读

### 2.8 学习统计页

参考文件：DIDI单词助记-学习统计页.svg（文件链接：https://miaoda-conversation-file.cdn.bcebos.com/user-asmovv53jmkg/conv-asmoxmbk70u8/20260407/file-asmrvq7e991g.svg）

- **统计维度一：学习时长与条目数量**

## 3. 业务规则与逻辑

### 3.1 本地数据持久化

- 所有条目数据（词库文件、易错词库、易错词表）、学习统计数据、设置项均持久化存储于本地数据库
- 关闭应用后数据不丢失，下次打开时自动加载

### 3.2 自动补充词性、音标与翻译

- 手动添加：用户点击「确认添加」后，系统对拆解出的单词与词组批量自动查询并填充词性、国际音标（IPA，词组音标可为空）与汉语翻译，输入过程中不触发任何自动查询
- 文件导入：解析完成后，对缺失词性、音标或翻译的条目自动补充
- 自动补充结果用户可手动修改；补充失败的字段留空并提示用户手动填写

### 3.3 文本智能拆词与词组识别规则

- 手动添加页大文本框支持输入单词列表、词组列表或整段文章
- 用户点击「确认添加」后，系统自动将输入内容拆解为独立英文单词与词组，去除标点、数字、停用词等非有效内容
- **词组判定规则**：由两个及以上英文单词组成的连续短语（如 break down、in spite of）识别为词组，整体作为一个条目入库，不拆分为单独单词
- 拆解结果以预览列表形式展示，用户可逐条修改后确认入库

### 3.4 文件内容自动解析与词性缩写过滤规则

- 导入 .txt、.csv、.xlsx、.doc、.pdf 格式文件时，系统自动识别文件内容，无论原始排版是否规范，均自动将内容分解为「单词/词组 + 词性 + 音标 + 汉语翻译」标准结构
- **词性缩写过滤**：解析过程中，若识别到词性缩写（包括但不限于 n.、v.、vt.、vi.、adj.、adv.、prep.、conj.、pron.、interj.、art.、num.、aux. 等），将其归入对应条目的词性字段，不得将其作为独立单词或词组写入词库
- **词组保留规则**：解析过程中，由两个及以上英文单词组成的连续短语识别为词组，整体作为一个条目保留，不拆分
- 解析后对缺失字段自动补充，完成后展示预览供用户确认
- 「确认导入」操作须将预览列表中所有条目正确写入本地数据库，写入完成后给出成功提示及本次导入条目数量

### 3.5 去重规则

- 去重开关开启时：
  - 手动添加：拆解预览列表中与数据库已有条目重复的项，自动标记并跳过，不写入数据库
  - 文件导入：导入完成后，给出明显提示「本次导入有 X 个重复条目已跳过」
- 去重开关关闭时：不执行去重，允许重复条目入库

### 3.6 词库文件管理规则

- 每次手动添加或文件导入时，条目归属于一个词库文件（新建或追加至已有文件）
- 词库文件支持重命名、删除（含二次确认）、预览
- 删除词库文件时，该文件下所有条目同步从数据库中移除

### 3.7 学习模式题库筛选规则

- 英汉模式、汉英模式、混合模式的选择页均支持多选词库文件作为题库
- 选择多个文件时，本次记忆的条目从所选文件中随机抽取，数量由用户设置的数量决定
- 若用户设置的数量超过所选文件（经条目类型筛选后）条目总数，则以实际条目总数为上限
- **条目类型筛选规则**：
  - 「仅单词」：从所选词库文件中仅抽取单个英文单词条目，排除词组
  - 「包含词组」/「全部」：从所选词库文件中同时抽取单词与词组条目
  - 筛选在随机抽题前执行，数量上限以筛选后的实际条目数为准

### 3.8 英汉模式选择题干扰项生成规则

- 每道题的 ABCD 四个选项中，一个为正确汉语释义，其余三个从词库中随机抽取其他条目的汉语释义作为干扰项
- 干扰项不得与正确答案重复

### 3.9 汉英模式填字符规则（方案A）

- 题干展示汉语释义，答案区域根据条目类型采用不同遮盖策略：
  - **单词**：部分字母显示，部分字母用「*」遮盖（如 F*t**r），遮盖字母数量与答案字母数一致
  - **词组**：所有字母全部用「*」遮盖，不展示任何字母提示；词组中的空格保持可见，不参与遮盖，每个单词内部字母均被遮盖
- 每个遮盖字符对应一个独立输入框，填写完一个字符后光标自动跳转至下一个输入框
- 页面下方 26 键键盘支持点击输入，点击字母后自动填入当前光标所在输入框

### 3.10 易错词权重规则

- 用户在英汉模式、汉英模式、混合模式下答错某条目时：
  - 若该条目不在易错词库中，则自动加入易错词库，初始出错权重值为 3
  - 若该条目已在易错词库中，则出错权重值 +3
- 用户在上述三种模式（含易错词专项练习）中答对某条目时：
  - 若该条目在易错词库中，则出错权重值 -1
  - 当出错权重值减至 0 时，该条目从易错词库中移除，并永久记录至易错词表
- 出错权重值最小为 0，不出现负值

### 3.11 易错词插入规则

- 仅当设置页中「易错词插入」功能开启，且学习模式选择页中「易错词插入」选项为勾选状态时，本规则生效
- 生效时，系统从易错词库中随机抽取「易错词插入数量」（设置页配置值，默认 10）个条目，追加至本次学习题目中
- 易错词插入数量不受用户设置的本次学习数量限制，两者相加为本次实际总题目数
- 若易错词库中条目数量不足「易错词插入数量」，则以易错词库实际条目数为上限
- 易错词插入的条目同样参与答题过程中的权重更新

### 3.12 易错词出现概率规则

- 在三种学习模式的随机抽题过程中，易错词库中的条目出现概率与其出错权重值正相关：出错权重值越高，被随机抽中的概率越大
- 具体概率计算方式：以各条目的出错权重值占当前题库（含易错词）所有条目权重总和的比例作为抽取概率；非易错词库中的普通条目默认权重值为 1

### 3.13 跟读发音匹配规则

- 用户点击「开始朗读」后，麦克风录制用户发音
- 系统将用户发音与标准发音进行匹配，计算匹配度百分比
- 匹配度 ≥ 设置页中「发音准确率阈值」时，判定为发音合格；低于阈值则判定为不合格

### 3.14 学习统计记录规则

- 每次进入答题页开始计时，退出或完成时记录本次学习时长，存入当日统计
- 每次答题完成后，记录本次答题的条目数与正确率，存入当日统计

## 4. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 本地词库为空时进入学习模式 | 提示「词库为空，请先添加单词」，并提供跳转至单词管理页的入口 |
| 文件导入格式不支持 | 提示「暂不支持该文件格式，请上传 .txt、.csv、.xlsx、.doc 或 .pdf 文件」 |
| 文件内容无法解析出有效单词或词组 | 提示「未识别到有效内容，请检查文件内容后重试」 |
| 确认导入写入数据库失败 | 给出具体失败原因提示，提供「重试」按钮，支持重新执行写入操作 |
| 自动补充词性、音标或翻译失败 | 对应字段留空并提示用户手动填写 |
| 手动添加大文本框内容拆解后无有效单词或词组 | 提示「未识别到有效英文单词或词组，请检查输入内容」 |
| 麦克风权限未授权 | 提示「需要麦克风权限才能使用跟读功能，请在系统设置中开启」 |
| 易错词库为空时进入专项练习 | 提示「暂无易错词，继续加油练习吧」 |
| 学习统计暂无数据 | 图表区域展示空状态提示「暂无学习记录」 |
| 所选词库文件条目数量不足以生成选择题干扰项 | 从全库随机补充干扰项；若全库条目数不足 4 个，提示「单词数量不足，请先添加更多单词」 |
| 用户设置记忆数量超过所选文件（筛选后）总条目数 | 自动调整为筛选后实际条目总数，并给出提示 |
| 条目类型筛选后所选词库中无符合条件的条目 | 提示「所选词库中无符合条件的条目，请调整筛选条件或添加更多内容」 |
| 易错词插入开启但易错词库为空 | 本次不插入易错词，正常按用户设置数量出题，无需额外提示 |
| 易错词插入数量超过易错词库实际条目数 | 以易错词库实际条目数为上限进行插入，并给出提示「易错词库仅有 X 个条目，本次插入 X 个」 |
| 文件解析时识别到词性缩写（如 n.、adj. 等） | 将其归入对应条目的词性字段，不写入词库作为独立条目 |
| 词组在汉英模式填字符时空格处理 | 词组中的空格保持可见，不参与遮盖，仅对各单词内部字母执行遮盖逻辑（全部遮盖） |

## 5. 验收标准

1. 应用打开即可使用，无任何注册、登录、网络账号相关功能与入口
2. 手动添加单词/词组后，关闭并重新打开应用，数据仍然存在
3. 文件导入支持 .txt、.csv、.xlsx、.doc、.pdf 五种格式，导入后条目正确解析并存入本地词库
4. 点击「确认导入」后，预览列表中所有条目正确写入本地数据库，不再出现「导入失败」提示；写入完成后展示成功提示及导入数量
5. 导入格式不规范的文件时，系统能自动识别并整理为标准格式
6. 手动添加与文件导入时，系统能自动补充缺失的词性、音标与汉语翻译
7. 手动添加页大文本框支持粘贴整段文章，点击「确认添加」后正确拆解为单词与词组列表并补充词性、音标、翻译，输入过程中页面无卡顿
8. 手动添加时，汉语翻译字段不出现非预期英文内容，自动补充仅在点击「确认添加」后触发
9. 单词管理页搜索栏支持即时筛选，每输入一个字符立即过滤列表
10. 去重开关开启时，重复条目不写入数据库；文件导入完成后正确提示跳过的重复条目数量
11. 词库文件列表支持重命名、删除（含二次确认）、预览功能
12. 英汉模式答题页为选择题模式，展示 ABCD 四个选项，选择后立即反馈正确/错误
13. 汉英模式答题页中，单词题目展示部分字母遮盖的填空提示，词组题目所有字母全部遮盖；字符输入框逐个填写，光标自动跳转，26 键键盘可正常点击输入；词组中空格可见不参与遮盖
14. 混合模式答题页英汉与汉英题型随机交替出现，两种题型均可正常作答；汉英题型中单词与词组遮盖规则与汉英模式一致
15. 英汉模式、汉英模式、混合模式选择页均支持多选词库文件、条目类型筛选（仅单词/包含词组/全部）与数量设置
16. 条目类型筛选为「仅单词」时，题库中不出现词组条目；筛选为「包含词组」或「全部」时，单词与词组均可出现
17. 答错的条目正确计入易错词库，初始权重为 3；后续答错 +3，答对 -1，权重归零时移出易错词库并记入易错词表
18. 易错词库页搜索功能正常可用，输入部分字母即可即时过滤，不出现「搜索失败」提示
19. 易错词库页搜索栏右侧排序条件可按出错权重值升序/降序切换，列表实时重新排列
20. 易错词库页下方「易错词表」永久展示所有曾被移出易错词库的条目，不因任何操作删除
21. 设置页「易错词插入」开关可正常开启/关闭，关闭时三种学习模式选择页中的「易错词插入」选项显示为灰色不可用
22. 设置页「易错词插入数量」滑动条可正常调整，默认值为 10
23. 三种学习模式选择页中「易错词插入」选项在功能开启时默认勾选，用户取消后下次进入自动恢复勾选
24. 易错词插入开启时，页面正确显示「本次学习单词数量为 X 个单词，易错词 Y 个，共计 Z 个」
25. 易错词权重越高的条目在三种学习模式中被随机抽中的概率越大
26. 跟读学习页可正常播放标准发音，麦克风录音后输出匹配度结果；词组可正常播放发音并进行跟读匹配
27. 发音准确率阈值在设置页可调整，跟读匹配判定结果与阈值一致
28. 学习统计页折线图正确展示每日/每月学习时长、条目数量与记忆正确率，按天/按月切换正常
29. 所有条目展示均包含词性字段
30. 所有页面跳转关系与原型一致
31. 所有文件格式（.txt、.csv、.xlsx、.doc、.pdf）导入时，词性缩写（n.、v.、adj.、adv. 等）不被写入词库作为独立条目，而是正确归入对应条目的词性字段
32. 文件导入时，由两个及以上英文单词组成的词组被整体保留为一个条目，不被拆分或过滤
33. 手动添加时，输入内容中的词组被整体识别并保留，不被拆分为单独单词
